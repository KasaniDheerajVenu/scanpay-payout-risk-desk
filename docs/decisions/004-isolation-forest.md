# ADR-004: Required database-first Isolation Forest pipeline

Status: accepted design, effectiveness unverified. Use one pooled unsupervised model on comparable eligible historical observations queried from PostgreSQL. Chronological validation, past-only features, explicit quality gates, model metadata and per-payout scores. Refit when eligible history/config changes or reuse exact compatible trusted model; never train on pending, fraud or unverified overrides. ML may cause actionable Manual review only; known fraud evidence required for Reject. Fallback is explicit, not a default-off implementation. Do not promise accuracy on small data. Keep fitted artifacts private; metadata in model_versions.
