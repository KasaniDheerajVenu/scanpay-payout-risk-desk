# ADR-007: Relational ingestion and repeatable evaluation runs

Status: accepted. CSV is a transport format, not a persisted document. Parse all five schemas into teams, transactions, payouts. Store batch/file metadata, model metadata, run and immutable results; use consistent database snapshot as sole training/inference source. Dedup exact records, reject conflicts except verified one-time disposition completion. New batches and evaluation versions share PostgreSQL rather than creating a database per batch. Model input manifest freezes accepted IDs/config/cutoffs. Retain prior results and override events, explicit run selection. Trade-off: more schema and upload workflow complexity, but reusable processing and reproducibility. General source corrections are deferred, not silently implemented.
